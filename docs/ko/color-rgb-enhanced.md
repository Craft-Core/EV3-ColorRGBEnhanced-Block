# 컬러 센서 RGB Enhanced — 사용 가이드

EV3 컬러 센서의 원시 RGB 및 HSVL 채널과 RGB 비교 모드를 제공하는 확장 블록입니다. **센서** 팔레트에 있습니다.

## 개념

표준 EV3-G 컬러 센서 블록은 7색 슬롯과 반사광/주변광만 제공합니다. 내부적으로 센서는 R, G, B 값을 보고하며 이 블록이 이를 노출합니다.

- **측정 – RGB** — 원시 0–255 빨강, 초록, 파랑 읽기.
- **측정 – HSVL** — RGB로부터 색조 (0–360°), 채도, 명도, 밝기 (0–100) 계산.
- **비교 – RGB** — 기준 R/G/B와 허용 오차로 비교, 부울 반환.

## 모드

| 모드 | 입력 | 출력 |
|------|-----|------|
| `ReadRGB` | 포트 | 빨강, 초록, 파랑 |
| `ReadHSV` | 포트 | 색조, 채도, 명도, 밝기 |
| `DectRGB` | 포트, R/G/B 기준, 허용 오차 | 빨강, 초록, 파랑, 일치 |
