# Датчик цвета RGB расширенный — Руководство

Расширенный блок датчика цвета EV3: сырые каналы RGB и HSVL, плюс RGB-сравнение. Вкладка **Датчик**.

## Концепция

Стандартный блок даёт только 7 цветов и отражённый/окружающий свет. Внутри датчик возвращает R, G, B. Этот блок их открывает.

- **Измерить – RGB** — читать сырые R, G, B (0–255).
- **Измерить – HSVL** — преобразовать в Оттенок (0–360°), Насыщенность, Яркость, Светлоту.
- **Сравнить – RGB** — сравнение с эталонным R/G/B с допуском, возвращает булево.

## Режимы

| Режим | Входы | Выходы |
|-------|-------|--------|
| `ReadRGB` | Порт | Красный, Зелёный, Синий |
| `ReadHSV` | Порт | Оттенок, Насыщенность, Яркость, Светлота |
| `DectRGB` | Порт, R/G/B-эталон, Допуск | Красный, Зелёный, Синий, Совпадение |

## Советы

- Калибруйте при реальном освещении.
- При меняющемся освещении используйте режим **Нормализация** Классификатора цвета.
