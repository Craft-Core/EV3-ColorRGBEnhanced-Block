# Классификатор цвета — Руководство

Классификация цвета по расстоянию для вкладки **Операции с данными**. Обучите до 8 эталонных цветов и определяйте, какой из них ближе всего к текущему RGB.

## Концепция

```
Нормализация: Rn = R / (R+G+B) × 100   (инвариант к освещению)
Setup ×8:     Сохранить один эталон на слот
Distance:     Для каждого слота n: D{n} = (R-Rn)² + (G-Gn)² + (B-Bn)²
Identify:     BestColor = argmin(D1..D8); BestDistance = min(D1..D8)
```

## Использование

1. В начале программы вызвать `Setup_C{n}` для n=1..8 с эталонными R, G, B.
2. В главном цикле: чтение RGB → Нормализация (опц.) → Distance → Identify.

## Режимы

| Режим | Категория | Описание |
|-------|-----------|----------|
| `Normalize` | — | Каждый канал / (R+G+B) × 100 |
| `Setup_C1`..`Setup_C8` | Настройка | Сохранить эталонный цвет в слот n |
| `Distance` | — | Квадрат расстояния от RGB к каждому из 8 слотов |
| `Identify` | — | Возвращает номер и расстояние ближайшего цвета |

## Советы

- Максимум 8 слотов.
- BestDistance — квадрат расстояния. Извлеките корень для реального евклидова расстояния.
- Identify всегда возвращает 1–8. Для "нет совпадения" проверяйте `BestDistance > порог`.
