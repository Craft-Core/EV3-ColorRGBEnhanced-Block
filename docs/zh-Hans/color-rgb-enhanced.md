# 颜色传感器 RGB 增强版 — 使用指南

扩展的 EV3 颜色传感器块，提供原始 RGB 和 HSVL 通道，以及基于 RGB 的比较模式。位于**传感器**选项卡。

## 概念

标准的 EV3-G 颜色传感器块只提供 7 色槽和反射光/环境光。传感器内部报告 R、G、B 强度值，本块将其暴露。

- **测量 – RGB** — 读取原始 0–255 的红、绿、蓝。
- **测量 – HSVL** — 从 RGB 计算色调 (0–360°)、饱和度、明度、亮度 (0–100)。
- **比较 – RGB** — 与参考 R/G/B 及容差比较，返回布尔。

## 模式

| 模式 | 输入 | 输出 |
|------|------|------|
| `ReadRGB` | 端口 | 红, 绿, 蓝 |
| `ReadHSV` | 端口 | 色调, 饱和度, 明度, 亮度 |
| `DectRGB` | 端口, R/G/B 参考, 容差 | 红, 绿, 蓝, 匹配 |

## 提示

- 在实际光照下校准。
- 光照变化时使用颜色分类器的**归一化**模式。
