# 颜色分类器 — 使用指南

用于**数据操作**选项卡的基于距离的颜色分类块。教导机器人最多 8 种参考颜色并识别实时 RGB 最接近哪种颜色。

## 概念

```
归一化:  Rn = R / (R+G+B) × 100    (光照不变)
Setup ×8: 每个槽位存储一种参考颜色
距离:    对每个槽位 n: D{n} = (R-Rn)² + (G-Gn)² + (B-Bn)²
识别:    BestColor = argmin(D1..D8); BestDistance = min(D1..D8)
```

## 使用

1. 程序启动时调用 `Setup_C{n}` (n=1..8) 配合参考 R、G、B。
2. 主循环：读取 RGB → 可选归一化 → 距离 → 识别。

## 颜色索引

`识别` 块返回 **1–8** 之间的数字。编号与颜色的对应关系是固定的：

| 编号 | 颜色 | 默认 R | 默认 G | 默认 B |
|------|------|--------|--------|--------|
| **1** | 红  | 255 | 0   | 0   |
| **2** | 绿  | 0   | 255 | 0   |
| **3** | 蓝  | 0   | 0   | 255 |
| **4** | 黄  | 255 | 255 | 0   |
| **5** | 白  | 255 | 255 | 255 |
| **6** | 黑  | 0   | 0   | 0   |
| **7** | 棕  | 128 | 64  | 0   |
| **8** | 粉红 | 200 | 50  | 150 |

> **重要：** 默认值是理想值。实际的EV3传感器输出的值要低得多。请用您的传感器测量每种颜色，并将测量值输入到Setup块中。
---|------|------|
| `Normalize` | — | 每通道 / (R+G+B) × 100 |
| `Setup_C1`..`Setup_C8` | 设置 | 在槽位 n 存储参考颜色 |
| `Distance` | — | 输入 RGB 到 8 个槽位的平方距离 |
| `Identify` | — | 返回最近颜色的索引和距离 |

## 提示

- 最多 8 个槽位。
- BestDistance 是平方距离。需要实际欧几里得距离请取 sqrt。
- Identify 始终返回 1–8。需要"无匹配"请检查 `BestDistance > 阈值`。
