# カラー分類器 — 使い方ガイド

**データー操作** パレット用の距離ベースのカラー分類ブロックです。最大 8 色の基準色を学習させ、ライブ RGB がどの基準色に最も近いかを判定します。

## 概念

```
正規化:    Rn = R / (R+G+B) × 100    (照明不変)
設定 ×8:   各スロットに基準色を保存
距離:      各スロット n について D{n} = (R-Rn)² + (G-Gn)² + (B-Bn)²
識別:      BestColor = argmin(D1..D8); BestDistance = min(D1..D8)
```

## 使い方

1. プログラム開始時に `Setup_C{n}` (n=1..8) を各基準 R, G, B 付きで呼び出す。
2. メインループ: RGB 読み取り → 任意で 正規化 → 距離 → 識別。

## 色番号一覧

`識別` ブロックは **1〜8** の数値を返します。番号と色の対応は固定です：

| 番号 | 色     | デフォルト R | デフォルト G | デフォルト B |
|------|--------|-------------|-------------|-------------|
| **1** | 赤     | 255 | 0   | 0   |
| **2** | 緑     | 0   | 255 | 0   |
| **3** | 青     | 0   | 0   | 255 |
| **4** | 黄色   | 255 | 255 | 0   |
| **5** | 白     | 255 | 255 | 255 |
| **6** | 黒     | 0   | 0   | 0   |
| **7** | 茶     | 128 | 64  | 0   |
| **8** | ピンク | 200 | 50  | 150 |

> **重要：** 上記のデフォルト値は理想値です。実際のEV3センサーははるかに低い値を返します。必ず各色を実際にセンサーで計測し、その値をカラー設定ブロックに入力してください。
----|---------|------|
| `Normalize` | — | 各チャンネル÷(R+G+B)×100 |
| `Setup_C1`..`Setup_C8` | 設定 | スロット n に基準色を保存 |
| `Distance` | — | 入力 RGB から 8 つの基準色までの二乗距離 |
| `Identify` | — | 最も近い色のスロット番号と距離を返す |

## ヒント

- スロット数は 8 固定です。
- BestDistance は二乗距離です。実際のユークリッド距離が必要なら sqrt を取ってください。
- Identify は常に 1–8 を返します。「一致なし」が必要なら `BestDistance > しきい値` をチェックしてください。
